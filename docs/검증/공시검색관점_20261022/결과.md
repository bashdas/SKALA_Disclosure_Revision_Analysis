# 공시별 근거 검색과 관점 판단 검증

## 변경 내용

shared.requests가 academic 검색어를 revision 또는 restatement가 포함된 고정 문구로 덮어쓰던 처리를 제거했습니다. 신규와 정정 모두 관점 에이전트가 현재 공시 및 질문에 맞춰 작성한 query를 사용합니다. 프롬프트에 외부 검색어는 공개 공시의 정보만 사용하고 비공개 메모 및 개인정보를 넣지 않도록 명시했습니다. 메모 원문 전체를 검색어로 자동 붙이는 처리는 추가하지 않았습니다.

키워드 기반 schedule_notice 판별과 입력 플래그를 제거했습니다. 공백 차이라는 이유로 모델 분석을 생략하던 typo_only 판별도 제거했습니다. safe_text의 투자 표현 및 검사 관련 키워드에 따른 문장 삭제를 제거하고 의미 판단을 출력 검사 모델의 프롬프트로 넘겼습니다. 메모 입력의 재무 키워드 우선순위도 검색된 원문 위치에 따른 우선순위로 바꿨습니다.

인증 정보 마스킹, 입력 형식과 URL 검증, 원문 일치 검증, 인증과 취소, 실행 예산 및 재시도 제한은 유지했습니다. 공식 제목의 유형 표기 및 등록 메타데이터 확인, 표 열 이름과 원문 위치 복원은 문서 구조와 출처 처리로 유지했습니다. 직접 적용 BPS 행과 계약명 및 계약금액의 같은 표 연결은 원문 정보 추출로 유지했고 이 정보만으로 관점 선택과 영향 분류를 확정하지 않습니다. 일반 문자열 검색 기능은 검색어에 맞는 원문을 찾는 데 사용합니다.

화면과 내려받는 보고서에 세 관점의 선택 및 미선택 이유를 관점 선택과 이유라는 한 영역에 표시했습니다. 기존 저장 보고서의 base.selected와 base.not_selected도 읽으므로 사진의 기존 결과에서도 재무 선택 1개와 미선택 2개를 함께 표시할 수 있습니다. 저장된 이유가 없으면 판단 기록 없음을 표시합니다. 과거 보고서 원문을 덮어쓰지 않았습니다.

## 검증

AI 자동 테스트 77개가 통과했고 실행 조건이 없는 2개는 건너뛰었습니다. 프런트엔드 전체 테스트 80개와 추가한 매핑 검사를 포함한 관련 테스트 10개가 통과했습니다. 현재 서로 다른 프런트엔드 검사 수는 81개입니다. 타입 검사와 빌드가 통과했습니다. 수정한 AI 파일의 Ruff 검사와 git diff --check가 통과했습니다. 전체 tests 폴더의 Ruff에서는 기존 test_markdown_file.py의 사용하지 않는 import와 import 순서 오류가 남아 있어 전체 폴더 통과로 보고하지 않았습니다.

신규 및 정정 입력에서 서로 다른 에이전트 검색어가 변경 없이 전달되는지 모의 테스트로 검증했습니다. 실제 외부 학술 검색 호출의 자료 적합성까지 검증한 결과는 아닙니다.

실제 모델 gpt-5.4-mini를 공시 20261015800457, 메모 eb4549f8-4650-4b8a-a961-5ea69891f123 1판과 고정된 도구 응답으로 1회 실행했습니다. 실행 한도는 기존 값을 유지했습니다. 모델이 FINANCE를 선택했고 관점 분석은 COMPLETED였습니다. INDUSTRY_CONTRACT와 FX_HEDGE의 미선택 이유가 같은 표에 포함됐습니다. 제안은 0개이고 KEEP 판단과 이유 및 검증된 공시 출처가 남았습니다. 모델이 추가 외부 조회를 요청하지 않아 실제 추가 외부 검색은 수행되지 않았습니다. 반복 검증을 완료했다고 해석하지 않습니다. API 입력, 최초 모델 응답과 필터 전후, 상태와 도구 호출, 최종 보고서는 final/run-1에 보존했습니다.

## 로컬 반영

ai-worker를 재빌드하고 실행 중인 작업이 없는 상태에서 재생성했습니다. 로컬 코드 및 프롬프트 32개 파일이 워커와 일치했습니다. 연동 MCP 3곳의 health 응답은 모두 200입니다. 프런트엔드는 기존 로컬 개발 서버에서 수정 소스를 사용합니다. 브랜치는 fix/contextual-evidence-perspectives이며 main은 변경하지 않았습니다. 커밋과 푸시는 수행하지 않았습니다.
