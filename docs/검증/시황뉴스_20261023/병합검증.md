# 리포트 참조와 시황 뉴스 병합 검증

기록 시각: 2026.10.23 11:04 KST
기준 main: 5bf4755

기존 증권사 리포트 참조와 네이버 시황 뉴스 구현을 main의 과거 공시 조회 및 메모 재검토 관점 기능과 병합했습니다. 충돌 파일 11개의 두 기능을 보존했고 미해결 Git 항목은 없습니다. 원래 변경은 stash 3b3f332727537ce6a4bb7131017292291bc8240b에 별도로 보존했습니다.

## 동작

네이버 제목과 링크를 3,600초마다 수집합니다. 활성 사용자의 즐겨찾기 기업과 경제 및 세계 공통 시황이 대상입니다. 모델이 저장 전에 기업명, 확인된 기업코드, 공통 시황 여부와 분류 이유를 추가합니다. 수집 목록은 30일간 보관합니다. 매시간 다음 수집에서 만료 항목을 삭제합니다. 본문은 수집 목록에 저장하지 않습니다.

MARKET_NEWS는 네 번째 선택 가능 관점입니다. 모델이 선택한 저장 기사 ID를 RAG MCP가 작업의 회사 및 기준 시각과 대조한 뒤 External MCP로 네이버 본문을 조회합니다. 기사 선택과 관점 선택은 모델의 판단을 유지합니다. 자료가 없거나 조회에 실패하면 한계를 남깁니다.

메모 ID와 고정 버전에 연결된 기존 테스트 리포트는 AI의 로컬 임베딩 검색으로 참조합니다. 메모 보완과 리포트 수정 검토는 실제 공시 근거와 리포트 위치를 확인한 항목만 보고서에 연결합니다. 과거 공시와 현재 공시의 비교 및 메모 재검토 관점도 함께 유지합니다.

## 병합 후 검증

| 검사 | 결과 |
| --- | --- |
| AI 전체 | 126개 통과, 외부 실행 조건이 필요한 2개 건너뜀 |
| External MCP | 95개 통과 |
| RAG MCP | 일반 검사 5개 통과, 별도 PostgreSQL 검사 1개 통과 |
| Business API | 별도 PostgreSQL에서 577개 통과, 실행 조건이 필요한 19개 건너뜀 |
| Core 마이그레이션 | 새 검증 DB에서 별도 17개 통과 |
| 프런트엔드 | 85개 통과, 타입 검사와 빌드 통과 |
| 정적 검사 | AI 소스와 테스트 Ruff 통과 |

추가한 공통 그래프 검사는 과거 원공시 확보, 리포트 참조 및 네 관점 실행을 같은 작업에서 확인합니다. 기사 본문 출처와 메모 보완 및 리포트 수정 위치가 기존 보고서 저장 계약에 함께 남습니다. 메모 원문도 보존됩니다. 모의 모델과 도구를 사용한 연결 검사이며 실제 모델의 네 관점 동시 성공을 뜻하지 않습니다.

실제 PostgreSQL 뉴스 검사는 중복 저장, 기업 및 공통 시황 검색 범위, 미래 기사 제외, 30일 삭제와 재시작 상태 보존을 확인했습니다. 고정 시각으로 59분 후 생략과 60분 후 실행, 수집 잠금의 중복 실행 방지도 검증했습니다. 실제 두 번째 정기 실행은 이번 병합 검사에서 관찰하지 않았습니다.

네이버 실제 조회에서는 삼성중공업 제목 목록 5개와 기사 본문 1,572자를 받았습니다. 기사 주소는 https://n.news.naver.com/mnews/article/032/0003478117 입니다. 수집과 실제 모델 분류 및 MCP 본문 조회의 앞선 실행 범위는 [기존 검증 기록](결과.md)에 보존했습니다.

기존 삼성중공업 고정 입력으로 실제 모델과 임베딩을 재실행했습니다. 첫 실행은 리포트 분석의 LengthFinishReasonError로 보완과 수정 검토가 누락됐습니다. 리포트 분석 출력 한도를 4,000토큰으로 조정하고 출처의 긴 인용을 반복하지 않도록 수정했습니다. 재실행에서 메모 보완 2건, 리포트 수정 검토 2건과 리포트 출처 3곳이 연결됐습니다. 임베딩은 18개였습니다. 업무 DB 저장과 다른 외부 도구는 로컬 응답으로 대체했으며 LOCAL_SAVED로 확인했습니다. 운영 전체 저장 성공으로 판정하지 않습니다.

## 트러블슈팅과 제한

병합 중 메모 보완 제안과 판단 보류 문구가 함께 나타날 수 있는 조건을 수정하고 회귀 검사로 확인했습니다. 별도 DB 검사의 최초 실행은 검증 DB 비밀번호를 잘못 지정해 접속에 실패했습니다. 컨테이너의 기존 검증용 설정을 출력 없이 읽어 재검증했습니다. 새 공통 그래프 검사의 첫 실행은 입력에 공시 유형이 빠졌고, 테스트 입력을 CORRECTION으로 명시한 뒤 통과했습니다.

실제 모델 재실행은 과거 공시와 뉴스 도구를 로컬 제한 응답으로 대체해 해당 미확인 경고가 남습니다. 출력 검사 가이드도 실행 한도로 완료하지 못한 경고를 남겼습니다. 전체 모델 판별 정확도와 모든 외부 자료의 의미적 일치는 보장하지 않습니다. 프런트엔드 빌드에는 기존 500kB 번들 경고가 남아 있습니다. 실행 중인 서비스의 이미지는 이번 병합 작업에서 재배포하지 않았습니다.

인증 환경 파일과 실행 캐시는 커밋에서 제외합니다. 기존 작업 기록과 자료는 보존합니다. SKALA 최상위에 새 항목을 생성하지 않았고 이번 테스트와 빌드의 캐시는 AI 산출물 경로로 지정했습니다. 기존 사용자가 보존한 build 및 환경 자료를 삭제하거나 전체 폴더 규칙 통과로 판정하지 않았습니다.
