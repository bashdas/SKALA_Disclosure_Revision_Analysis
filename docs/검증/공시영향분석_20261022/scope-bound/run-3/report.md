- 재무와 실적: 근거 부족으로 미작성
- 정정 전후 계약금액은 전체 계약 범위가 2척에서 1척으로 달라지는 비교이므로, 잔존 선박 1척의 개별 종전 금액 변동으로 해석할 수 없습니다.
- 공시는 취소 선박의 제3자 매각 계획을 언급하지만 실제 매각 완료, 대금 회수, 잔존 선박 인도 및 잔금 회수 완료 여부는 확인되지 않았습니다.
- 기존 메모의 목표주가 산정은 2027 BPS 8,231원과 Target P/B 4.3배에 근거하므로, 이번 정정이 해당 입력값을 직접 변경하는지 확인되지 않아 수치 수정은 보류합니다.
- 현재 입력에는 계약 정정의 계약금액 변경만 확인되며, 기수취한 선수금 규모, 제3자 매각 추진 일정, 잔존 계약 선박의 인도와 잔금 회수 여부는 확인되지 않았습니다.
- 메모는 2027 BPS 8,231원과 Target P/B 4.3배, 적정주가 35,394원, 목표주가 35,000원을 제시하지만, 해당 목표주가 산정에 선수금 회수나 제3자 매각대금, 잔존 선박 인도 여부가 어떻게 반영되었는지는 근거가 부족합니다.
- 정정 공시는 원유운반선 2척에서 1척으로 계약 범위가 축소되었음을 보여주지만, 취소된 선박의 제3자 매각 및 비용 회수 계획과 잔존 선박의 개별 종전 금액은 확인되지 않아 개별 선박별 영향 분석은 보류합니다.
- 출력 검사 가이드에서 추가 검토가 필요한 문장을 확인했습니다.
