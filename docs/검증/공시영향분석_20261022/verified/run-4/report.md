## 확인 범위와 남은 질문

- 기존 메모에는 개별 수주 계약이나 인도 일정에 대한 직접 문장이 없어, 정정공시와 메모의 수치 연결을 확정할 근거가 부족합니다.
- 정정공시에는 취소된 1척의 제3자 매각 계획과 선수금 회수 계획은 있으나, 실제 매각 완료와 비용 회수 완료는 확인되지 않아 완료 사실로 쓸 수 없습니다.
- 잔존 1척의 정상 인도와 잔금 회수 여부는 현재 입력에서 확인되지 않아 판단을 보류합니다.
- before\_text는 메모 원문에서 연속된 구간을 그대로 복사했으며, 분리된 문장이나 표를 결합하지 않았습니다.
- 현재 입력에는 취소된 1척의 제3자 매각 계약 체결, 매각대금 수령, 건조비 회수 완료를 확인하는 후속 공시가 없습니다.
- 현재 입력에는 잔존 1척의 실제 인도 완료와 잔금 회수 완료를 확인하는 직접 근거가 없습니다.
- context\_truncated가 true이므로 보이지 않는 부분의 내용을 추정하지 않았습니다.
- 입력 메모에는 계약 취소분의 선수금, 매각대금, 건조비 회수의 실제 회계 반영 시점이나 금액 조정 내역이 없어서 매출 인식과 현금흐름 반영 여부를 확정할 수 없습니다.
- 입력 메모에는 목표주가 산정의 입력값으로 사용된 BPS와 적용 배수가 제시되어 있으나, 이번 정정공시가 그 수치에 반영되었는지 확인하는 후속 자료가 없습니다.
- context\_truncated가 true이므로 보이지 않는 정정 전후 상세 문구나 후속 재공시 여부를 추정하지 않았습니다.
- 출력 검사 가이드에서 추가 검토가 필요한 문장을 확인했습니다.
