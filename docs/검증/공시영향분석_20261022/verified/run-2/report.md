같은 문서에는 기수취한 선수금과 해당 선박의 제3자 매각 추진을 통해 건조비를 보전할 계획이라고만 되어 있어, 이는 회사의 계획으로 확인되며 현재의 진행 완료 사실은 아닙니다.
잔여 1척에 대해서는 2호선의 인도일이 선주측 사정에 따라 변경될 수 있고 변경 확정 시 재공시하겠다고 되어 있어, 정상 인도와 잔금 회수 완료 여부는 현재 자료만으로 확인되지 않습니다. [근거 4] [근거 1] [근거 2] [근거 3]

공시에는 기수취한 선수금 규모와 제3자 매각으로 확보할 매각대금의 구체적 금액은 제시되지 않았고, 회사는 해당 선수금과 매각대금으로 건조비를 보전할 계획이라고만 적시하였습니다.
