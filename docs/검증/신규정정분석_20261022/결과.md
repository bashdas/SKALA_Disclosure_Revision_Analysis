# 신규공시와 정정공시의 기존 메모 분석 지원

신규공시에도 분석하기 버튼을 표시하고 기존 메모와 버전을 선택해 접수하도록 변경했습니다. 초기 메모 생성 경로는 추가하지 않았습니다. 기존 메모 원문은 보존하고 별도 분석 보고서를 저장합니다.

등록 공시의 filing_type과 is_correction을 작업별 내부 컨텍스트로 전달합니다. AI는 이 정보와 공식 조회의 metadata_status 및 report_name을 확인합니다. 확인된 유형이 상충하거나 정보가 없으면 UNKNOWN 경로에 사유를 남깁니다. 정정표가 없는 경우에도 메타데이터가 정정공시이면 CORRECTION 경로를 유지합니다.

LangGraph의 IMPACT_NEW, IMPACT_CORRECTION, IMPACT_UNKNOWN에서 유형별 기본 분석 기준을 적용합니다. 수집과 메모 RAG, 관점 선택과 병렬 분석, 추가 근거 조회와 재분석, 보고서 저장은 기존 흐름을 공유합니다. 기본 분석의 공통 메모 연결 검증도 재사용합니다.

신규공시 경로는 구조화 정정 전후 항목을 전달하지 않습니다. 확인된 공시 본문을 기존 메모 문장과 수치 및 가정과 비교하며 기존 전망 반영 여부가 불명확하면 재검토 질문과 보류를 남깁니다. 정정공시 경로는 검증된 정정표와 본문을 사용하며 불완전한 표에는 제한 사유를 표시합니다. 영향 없음은 수정 없음과 유지 이유 및 연결 근거를 표시합니다. 실제 메모 문장 또는 검증 가능한 출처가 없는 제안은 보류합니다.

## 실제 모델과 고정 자료 재생

동일한 삼성중공업 메모 버전 1과 보존된 실제 공시를 사용했습니다. 신규공시는 20250618800387, 정정공시는 20260203800709입니다. 실제 모델을 호출했고 원문 조회와 메모 검색은 보존된 자료 및 결정적인 문서 검색으로 재생했습니다. 업무 DB 저장은 이 재생 검증에서 수행하지 않았습니다. 전체 입력, 최초 응답, 검사 전후 결과와 최종 보고서는 NEW 및 CORRECTION 하위 폴더에 있습니다. 모델명과 설정은 conditions.json에 기록했습니다.

| 유형과 실행 | 실제 기본 경로 | 선택 관점과 결과 | 정정 항목 | 메모 보존 |
| --- | --- | --- | --- | --- |
| 신규 1 | NEW | 재무 완료 | 0개 | 확인 |
| 신규 2 | NEW | 재무, 기업과 산업 및 계약 완료 | 0개 | 확인 |
| 정정 1 | CORRECTION | 기업과 산업 및 계약, 재무 완료 | 4개 | 확인 |
| 정정 2 | CORRECTION | 재무, 기업과 산업 및 계약 완료 | 4개 | 확인 |

신규 결과 2건 모두 정정표와 공시의 정정 전후 구조를 생성하지 않았습니다. 기존 BPS에 계약 해지 영향이 반영됐는지는 확인이 필요하다고 보류했습니다. 신규 1은 재무만 선택했고 신규 2는 계약 관점도 선택해 관점 수에 변동이 있었습니다. 정정 1에는 동일 문장을 반환한 FACT_UPDATE 항목이 있었고, 보고서의 기존 표시 규칙에 따라 유지 제안으로 표시됐습니다. 저장된 원래 분류는 보존했습니다. 조건부 해석과 개별 출처의 의미 적합성은 모델 출력에 변동이 있을 수 있습니다.

## 실제 로컬 워커 실행

실행 중인 Business API, Business MCP, External MCP, RAG MCP와 RabbitMQ를 사용했습니다. 기존 로컬 검증 계정의 메모와 등록 공시를 사용했고 새 메모를 생성하지 않았습니다. 다음 실행 전체를 기록했습니다.

| 작업 ID | 유형과 공시 | RAG | 관점 | 최종 결과 |
| --- | --- | --- | --- | --- |
| d958a846-2828-45e7-b767-5c03fa7463b5 | 신규, 20261020800733 | 색인과 검색 성공 | 재무 완료 | 제한 사항을 포함해 보고서 저장 |

| 7ef8f793-4ebd-4170-a0a2-0906eafb17c0 | 정정, 20261020000245 | 색인과 검색 성공 | 미선택 | 제한 사항을 포함해 보고서 저장 |

신규 실제 보고서의 analysis_type은 NEW이며 corrections는 빈 배열입니다. 정정 실제 보고서는 CORRECTION으로 저장됐습니다. 관점 미선택은 해당 공시와 선택한 기존 메모의 분석 결과이며, 공통 다관점 실행 여부는 고정 자료 재생과 모의 테스트에서 별도로 검증했습니다. 실제 워커 결과와 실행 기록은 live로 시작하는 파일에 보존했습니다. 인증 정보는 포함하지 않았습니다.

색인 시간 초과 원인은 이번 작업에서 확정하거나 수정하지 않았습니다. 시간과 재시도 한도도 변경하지 않았습니다. 이후 정정공시 실행에서는 같은 RAG 경로가 성공했으며, 실패한 앞선 실행도 보존했습니다. 모든 공시의 색인이 시간 한도 내 완료된다고 보장할 수 없습니다.

## 로컬 반영과 화면 확인

Business API와 AI Worker를 재생성했습니다. 워커의 Python 및 프롬프트 파일 32개가 작업 소스 해시와 일치했고, 백엔드 수정 파일 3개도 컨테이너와 일치했습니다. 프론트엔드는 실행 중인 Vite 서버에 반영됐습니다. 브라우저에서 신규공시의 분석하기 버튼으로 기준 메모 선택 모달이 열리는 것을 확인했습니다. 검증 계정의 해당 기업에는 연결된 메모가 없어 실제 브라우저에서 버전 선택 후 접수까지는 수행하지 않았습니다. 메모와 버전 선택 후 접수는 컴포넌트 테스트와 HTTP 테스트에서 확인했습니다.

브랜치는 feat/new-disclosure-memo-analysis입니다. main은 2f248ad072be2d0dba3770e353c6b0ea3060efb9를 유지했습니다. 이번 변경의 커밋과 푸시는 수행하지 않았습니다. 이전에 중단한 카드 화면 표시 수정도 포함하지 않았습니다.
