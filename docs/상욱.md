### 트러블슈팅
- 초기 기본 실행은 토큰 사전 다운로드와 로컬 포트 제한으로 실패했다. 승인받은 실행으로 재검증하여 기준 검사를 통과했다.
- 모듈 분리 직후 호환 import와 테스트 대체 객체 주입 경로가 달라진 오류를 수정했다. 최종 회귀 검사를 통과했다.
- OpenAI의 길이 제한 예외를 Adapter가 내부 예외로 바꾸므로 해당 테스트의 예외 기대값을 갱신했다. 1회 복구와 누적 호출 예산 검증은 유지했다.
- wheel 로컬 분석도 별도 작업 디렉터리의 토큰 사전이 없어 네트워크 제한에 걸렸다. 승인받은 실행으로 패키지 검증을 통과했다.

### 남은 작업
- 구조 분리는 완료했다. Registry만으로 새 관점의 모델 스키마·백엔드·화면 계약이 자동 확장되지는 않으며 별도 갱신이 필요하다.
- RunRepository의 기존 SQLite db/lock 계약과 Harness의 기본 Gateway 지연 생성 호환 경로는 구조 문서에 한계로 명시했다.
- 기존 경고 누락, SEC 추가 조회 날짜, 최종 검사 예산, 긴 문맥 축약 정책은 이번 리팩터링에서 동작 변경 없이 후속 과제로 남겼다.
