HomeView의 MY RESEARCH 문구를 제거했습니다. 이번 대화의 시세 조회, 기업별 메모 분리, 목록 배치와 안내 제거 및 누적 변경을 사용자 요청에 따라 함께 커밋합니다. README의 이전 시세 미제공 설명과 일반공시 분석 버튼 설명을 현재 동작에 맞췄습니다.

### 검증 결과
프론트 타입 검사와 프로덕션 빌드를 통과했습니다. 직전 프론트 단위 검사 32개가 통과했고 이번 변경은 정적 문구 한 줄 삭제입니다. 백엔드 전체 검사에서 243개가 통과하고 테스트 DB가 필요한 344개는 건너뛰었습니다. SEC 검사 두 개가 통과했습니다. 앞선 기업별 메모 검증에서 별도 테스트 DB로 확인한 결과는 위 기록에 있습니다.

### 트러블슈팅
SEC 검사 최초 실행에서 공유 패키지 경로를 빠뜨려 가져오기가 실패했습니다. PYTHONPATH에 backend/shared를 추가한 뒤 두 검사가 통과했습니다.

### 남은 작업
커밋과 원격 반영 결과는 Git 명령 결과를 확인해 최종 응답에서 구분합니다.
